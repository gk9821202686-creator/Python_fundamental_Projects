# Python_fundamental_Projects
It contain all fundamental concepts of python :-

Basic Data Types & Variables: 
Primitives (int, float, str, bool), dynamic assignment, and explicit type conversion.

Input & Output: 
Capturing user input with input() and formatting console output using print() and f-strings.

Operators: 
Arithmetic (+, -, *, /), comparison (==, !=, >, <), and logical (and, or, not) operations.

Control Flow:

Decision-making with if/elif/else and iteration using for/while loops with break and continue.

Data Structures:
Managing ordered sequences with lists/tuples, unique items with sets, and key-value mapping with dictionaries.

Functions: 
Modularizing code using def, handling arguments, returning values, and managing variable scope.

Object-Oriented Programming: 
Defining classes/objects, constructors (__init__), encapsulation, inheritance, polymorphism, and abstraction.
